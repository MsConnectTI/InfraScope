# Network Monitor

Sistema de monitoramento de conexões de rede desenvolvido para estudo e monitoramento da infraestrutura.

## Arquitetura

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB
- Agent: PowerShell / futuramente Windows Service
